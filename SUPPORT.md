# Support

- Use [GitHub Discussions](https://github.com/Umah-Creative/baithani-winner-picker/discussions) for setup, deployment, and usage questions.
- Use the [bug report form](https://github.com/Umah-Creative/baithani-winner-picker/issues/new?template=bug.yml) for reproducible defects.
- Use the [feature request form](https://github.com/Umah-Creative/baithani-winner-picker/issues/new?template=feature.yml) for product proposals.
- Use private vulnerability reporting for security issues; see [SECURITY.md](SECURITY.md).

This community repository does not promise a response or resolution deadline. Please provide versions, logs with secrets removed, and exact reproduction steps.
