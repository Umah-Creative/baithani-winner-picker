# Security policy

## Supported version

Security fixes target the current `main` branch. Older commits and immutable container tags are retained for traceability, not maintained as separate supported releases.

## Report a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's **Report a vulnerability** flow in the repository Security tab so details remain private.

Include the affected route or component, reproduction steps, impact, and any suggested mitigation. Never include real deployment passwords, signing secrets, database credentials, cookies, or personal data.

For sensitive coordination when GitHub private reporting is unavailable, contact `richie.permana@gmail.com`.

General setup questions belong in [Discussions](https://github.com/Umah-Creative/baithani-winner-picker/discussions) or the support channels described in [SUPPORT.md](SUPPORT.md).
