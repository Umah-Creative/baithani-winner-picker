# Agent Collaboration

## Authority And Discovery

- Read nearest applicable instruction files before changing a task area.
- Deeper local instructions override broader instructions.
- Start with user-named paths before broad search.
- Discover project truth from code, configuration, tests, and local documentation instead of guessing.

## Boundaries

- Keep investigation read-only unless change authority is explicit.
- Preserve unrelated worktree changes.
- Do not widen scope without explaining why extra context or work is needed.
- Ask before a choice that materially changes product behavior, architecture, or external state.

## Delivery

- State assumptions when they affect outcome.
- Keep findings evidence-backed and concise.
- Record blockers plainly; do not disguise unverified work as complete.
- Prefer focused verification matching changed scope.
